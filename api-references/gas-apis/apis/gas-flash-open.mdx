---
title: 能量速充
api: POST /api/tron/gas/flash/open
description: "创建TRON能量速充订单"
---

能量速充固定使用 `service_charge_type=10000`，无需传入 `service_charge_type`。

<Note>
  - 仅支持已激活且满足速充规则的TRON地址；购买数量过低或地址当前能量状态不满足速充条件时，下单会被拒绝。
  - 订单采用异步处理模式，本地订单创建并完成资金冻结后立即返回 `trade_no`；后续进度与结算明细可通过 [查询记录](/api-references/gas-apis/apis/gas-record-list) 接口的 `swap_info` 字段查询。
  - **资金冻结**：下单时按预估实际代理能量数量上浮一定安全余量，结合下单时的能量单价与用户费率冻结费用，冻结金额可能略高于按 `energy_num` 估算的费用。
  - **费用结算**：能量回收完成后，按系统最终确认的实际计费能量数量与下单时的价格、费率快照计算实际费用，从冻结金额中扣除，剩余部分自动解冻返还可用余额。
  - **订单失败**：冻结金额全额解冻返还可用余额，不产生任何费用。
</Note>

#### 请求参数数据结构

<ParamField query="request_id" type="string" required>
  业务方唯一请求ID。同一账户下不可重复。
</ParamField>
<ParamField query="receive_address" type="string" required>
  能量接收地址，只支持单个地址。
</ParamField>
<ParamField query="energy_num" type="integer" required>
  用户购买的能量数量。最终计费以回收完成后系统确认的实际计费能量数量为准，可能与购买数量存在少量偏差，可通过查询记录接口的 `swap_info` 查看结算明细。
</ParamField>
