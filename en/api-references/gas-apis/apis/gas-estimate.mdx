---
title: Estimate Order Amount
api: GET /api/tron/gas/estimate
description: "Estimate TRON Energy costs; supports resource estimation for standard token transfers and contract calls."
---
<Note>
    The current API estimates only TRON Energy costs; it does not include Net (bandwidth) costs.

    The following estimation scenarios are supported:
    - Standard token transfers: Do not provide `amount` or `data`.
    - Contract invocation transactions: Provide the ABI-encoded `data` (in hex format).
</Note>
#### Request Parameters

<ParamField query="receive_address" type="string" required>
    receive addres
    <Note>Please ensure that the received address holds the token corresponding to the contracted_address, otherwise the miner fee estimation will fail</Note>
</ParamField>
<ParamField query="address_to" type="string" required>
    The transfer address for estimating miner fees.
    <Note>
        - Standard token transfer scenario: `address_to` is the actual recipient address.
        - Contract invocation transaction scenario: `address_to` is the contract address, and it must match `contract_address`.
    </Note>
</ParamField>
<ParamField query="contract_address" type="string" required>
    Contract address for estimating miner fees.
</ParamField>
<ParamField query="service_charge_type" type="string" required>
    rent time code: Request the order/price interface to return the cost codes for
    minutes, hours, days, and different times.
    <p>eg:10010 - 10 minutes, 20001 - 1 hour, 30001 - 1 day</p>
</ParamField>
<ParamField query="amount" type="string">
    Contract invocation amount
    <Note>
        When used for contract estimation scenarios, `amount` represents the value associated with the contract invocation. This parameter is optional for standard transfer estimation scenarios.
    </Note>
</ParamField>
<ParamField query="data" type="string">
    Contract invocation data; hexadecimal data constructed via ABI encoding.
    <Note>
        If `data` is provided, the API treats the request as a contract transaction for resource estimation; this parameter is optional for standard transfer estimation scenarios.
    </Note>
</ParamField>


#### Response Parameters

<Expandable title="object">
    <ResponseField name="contract_address" type="string">contract address</ResponseField>
    <ResponseField name="address_to" type="string">transfer address</ResponseField>
    <ResponseField name="receive_address" type="string">receive address</ResponseField>
    <ResponseField name="amount" type="decimal">order amount</ResponseField>
    <ResponseField name="energy_amount" type="decimal">energy amount</ResponseField>
    <ResponseField name="active_amount" type="decimal">active amount</ResponseField>
    <ResponseField name="energy_num" type="integer">energy num</ResponseField>
    <ResponseField name="energy_price" type="decimal">energy price</ResponseField>
    <ResponseField name="service_charge_type" type="string">rent time code</ResponseField>
</Expandable>
